# Panda-RPKI

Panda-RPKI is an open-source RPKI Relying Party (RP) implementation written in Rust.

It retrieves and validates RPKI data and produces validated routing information for routing systems and other applications.

Panda-RPKI is currently under active development and testing. The current implementation may contain bugs, incomplete features, or unexpected behavior.

We welcome feedback from the community and appreciate help in identifying potential issues and improving Panda-RPKI. Please feel free to open an issue or submit a pull request.
